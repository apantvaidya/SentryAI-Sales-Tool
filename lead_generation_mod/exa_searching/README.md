# Exa Searching Code Folder

This folder holds the code for the Exa-first phase of the MVP.

## Purpose

- load the `.txt` query templates from `exa_payload_templates/`
- call the Exa API
- map Exa structured entities into our internal schema
- filter and deduplicate candidates
- write JSON outputs into `data/`
- leave `public_business_email` empty for now
